# R9 — 정지 안정화와 간결한 계측 화면

## 적용 전 알아둘 점

이번 수정은 정지 상태의 변위 표시를 −5\~+5 mm 안에 유지하는 것을 목표로 합니다. **실제 장비에서 ±5 mm를 달성했다고 검증한 버전은 아닙니다.** 영상에는 표시값과 일부 거리 통계가 있지만, 전체 원시 거리 시계열과 실제 안테나 좌표는 없어 동일 조건을 재생할 수 없습니다.

정지 안정화를 우선해 긴 평균을 기본으로 적용했습니다. 초기 0점 보정은 약 15\~20초, 이후 평균 수집은 10\~120초입니다. 변형을 준 뒤에도 긴 평균 때문에 수십 초에서 약 2분 이상 걸릴 수 있습니다. 짧은 변형은 작게 보일 수 있으므로 빠른 변형 실험에는 상세 설정의 ‘변형 추적’을 사용하세요. 모드를 바꾸면 정지 시 흔들림도 달라집니다.

R9에서는 Tag 및 Anchor 펌웨어는 바꾸지 않고 웹 화면과 Node.js 서버만 수정했습니다.

## 적용 순서

1. 실행 중인 서버를 Ctrl+C로 종료합니다.
2. 기존 `.env`의 API 키·포트 설정을 옮기되, 아래 세 설정은 반드시 R9 값으로 수정합니다. 운영체제 환경변수에 같은 설정이 있으면 그 값이 우선합니다.

```text
UWB_CAL_SAMPLES_V10_1=180
UWB_CAL_MIN_MS_V10_1=15000
UWB_FILTER_MODE_V9=stable
```

기존 `UWB_FILTER_MODE`는 R9에서 사용하지 않습니다. `.env`가 없으면 위 값이 기본입니다. 예제는 `.env.example`에 있습니다.

3. `package.json`이 있는 UI 폴더에서 PowerShell로 실행합니다. Node.js 20.12 이상을 사용합니다.

```powershell
npm.cmd ci
npm.cmd start
```

4. `http://localhost:8080`에 접속해 Ctrl+F5로 새로고침합니다. 기존처럼 모델, ID 매핑, 실물 좌표를 확인합니다. 모델 추천 좌표가 실물 안테나 중심과 다르면 ‘상세 데이터 · 설정 → UWB 실험 · 실제 좌표 설정’에서 수정합니다. X/Z는 수평, Y는 수직, 단위는 m입니다.
5. 구조물을 **원위치에 고정**하고 ‘0점 보정’을 한 번 누릅니다. 보정 중에는 변형을 주지 않습니다. 약 10 Hz 수신 기준 약 15\~20초이며, 순간 누락이나 짧은 IMU 진동은 진행률을 초기화하지 않고 잠시 수집만 멈춥니다.
6. 보정 완료 뒤 ‘평균 수집’도 끝날 때까지 기다립니다. 준비 중 숫자는 참고로 보이지만 정지 검사에는 사용하지 않습니다.
7. ‘정지 60초 검사’를 누르고 원위치를 유지합니다. 보정 전에 눌러도 준비가 끝난 뒤 자동으로 검사합니다. 준비가 5분을 넘으면 시간 초과가 표시됩니다.
8. 검사 종료 후 ‘검사 CSV 저장’을 누릅니다. **한 번이라도 유효값의 절댓값이 5 mm를 넘으면 목표 미달**입니다. 기준선을 옮겨 통과시키지 않습니다. 실패한 경우도 CSV를 저장하세요.

변위를 준 상태에서 ‘0점 보정’을 다시 누르면 그 위치가 새 기준점이 됩니다. 실제 변형을 비교하는 동안에는 누르지 마세요.

## 화면 변경

- 기본 화면: 큰 수직 변위, 현재 평균 시간, 기울기·진동·UWB 응답 수, 0점 보정·정지 검사·CSV 버튼.
- 거리 4개, 불확도, 보정값, 좌표 입력, 계측 모드 등은 ‘상세 데이터 · 설정’ 안으로 이동.
- 중앙의 AI 분석 진행 내역은 기본적으로 접힘.
- 낮은 수직 감도만으로 계산 가능한 값을 숨기지 않음. 참고값임을 상태 문구로 표시.

## 처리 변경

| 항목 | R8 | R9 기본값 |
| --- | --- | --- |
| 0점 보정 | 200개·최소 20초 | 180개·최소 15초(약 15\~20초) |
| 거리 평균 창 | 약 0.3초 | 보정 잡음·수직 감도에 따라 10\~120초 |
| 출력 평활화 시정수 | 0.25초 | 4초 |
| 초기 출력 | 초기 필터 상태에 의존 | 실제 추정값에서 시작 |
| 정지 시험 | 일반 CSV 수집 | 보정·평균 이후 별도 60초 판정 |

거리 평균은 양쪽 꼬리 각 20%를 제외한 평균입니다. 보정과 측정에 같은 중심값 계산을 사용하며, 보정 완료 후 링크별 bias는 고정합니다. 범위를 ±5 mm로 자르거나 작은 값을 0으로 바꾸지 않습니다. 진동이 없다는 이유로 측정값을 강제로 고정하지도 않습니다.

평균 시간의 자동 선택은 약 10 Hz의 독립 잡음을 가정한 근사 계산입니다. 상관 잡음·장시간 드리프트·좌표 오차에 대한 정확도 보장이 아닙니다. 창 길이는 최대 120초로 제한하며, 그 안에서 목표를 만족하지 못하면 검사 결과에 그대로 나타납니다. ‘불확도’는 원시 거리 잡음에 기반한 보수적 진단값이며, 평균 후 실제 오차를 측정한 값은 아닙니다.

‘변형 추적’과 ‘짧은 평균’은 상세 설정에 남아 있습니다. 모드 변경은 모든 브라우저에 공통 적용되고 bias는 유지되지만 필터는 다시 준비합니다. 서버 재시작 시 `.env` 기본 모드로 돌아갑니다.

## 정지 검사의 의미

검사는 원위치에서 변위 0 mm가 참값이라는 사용자 조건을 전제로 합니다. 검사 시작 때 평균을 빼거나 다시 보정하지 않습니다. 60초간 최소 100개 유효 샘플, 수집 데이터의 95% 이상 유효, 최대 수신 공백 1.5초 이하, 진동 미감지를 요구합니다. 보정·태그·재시작·모드 변경은 검사를 중단합니다. 재연결 뒤 다시 평균을 수집하는 데이터는 유효 검사 샘플에서 제외합니다.

통과는 **이번 60초의 필터 출력**에 대한 결과입니다. 장시간 정확도, 5 mm 실제 변위의 검출 능력, 빠른 응답을 보증하지 않습니다. 다음에는 정지 시험과 별도로 실제 변위를 다른 기준기로 측정해 비교해야 합니다.

CSV의 `raw_range_m`은 수신한 원시 거리입니다. `raw_geometry_mm`은 고정 bias를 보정한 현재 수신 거리에서 계산한 값이며 시간 평균 이전 값입니다. 기하 계산이 불가능하면 비어 있을 수 있습니다. 필터·보정 ID와 기준선, 원시·평균 거리를 함께 저장합니다.

## 영상과 물리 배치

첨부 영상의 여러 화면에서 정지 표시값이 −59.4 mm, +45.4 mm 등으로 움직였고, 일부 링크의 거리 잡음 지표가 약 26\~46 mm로 보였습니다. 이는 화면에서 읽은 예시이며 전체 영상의 최솟값·최댓값 통계는 아닙니다.

현재 코드의 수직 감도는 높이 차 h와 거리 r에 대해 h/r입니다. 감도 0.20이면 작은 수직 변위 5 mm가 한 링크에서 약 1 mm의 거리 변화로 나타납니다. 화면에 보이는 수 cm 거리 잡음보다 훨씬 작으므로 단순 필터만으로 정밀성과 반응 속도를 동시에 확보하기 어렵습니다.

실제 좌표와 안테나 중심을 먼저 맞추고, 가능한 고정 지점에서 Tag와 Anchor의 높이 차를 늘리거나 수평 거리를 줄여 감도가 개선되는지 확인하세요. 모든 Anchor는 변형되는 구조물과 독립적으로 고정되어야 합니다. 현재 해석은 Tag의 X/Z가 고정이고 Y만 변한다고 가정하므로 옆 이동·회전이 섞인 실험에서는 수직 변위와 달라질 수 있습니다.

## 소프트웨어 검증

`VALIDATION_R9.md`에 가상 시험의 통과·실패 결과를 모두 기록했습니다. 가상 잡음은 실제 영상의 원시 로그를 복원한 것이 아닙니다. 별도 기준기와 실제 정지 CSV가 없어 실물 정확도는 검증하지 못했습니다.

```powershell
npm.cmd run test:static
npm.cmd run test:static-check
npm.cmd run test:uwb
npm.cmd run test:tracking
npm.cmd run test:precision
npm.cmd run test:bridge
```

브라우저에서는 접힌 상세 화면, 검사 버튼, 모드 변경, CSV 다운로드, 노트북 폭에서의 계측 패널 표시를 확인했습니다. 브라우저 검증용 데이터는 모의 데이터입니다.
